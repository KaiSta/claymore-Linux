# Cline project rules

Read the root `AGENTS.md` before editing. Use `docs/code-map.md` for ownership and navigation when a task spans multiple modules; do not load the whole repository by default. The portable skill is `skills/code-map/SKILL.md`.

Keep changes minimal and run the narrowest relevant `make` check. Preserve the protocol invariants in `docs/PROTOCOL.md` and `docs/code-map.md`; do not hand-edit generated `src/layout_data.cpp`.
